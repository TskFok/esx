# Console 字段折叠设计

## 目标

让 Console 的请求内容和未截断的返回内容支持按对象与数组层级折叠字段，便于浏览较大的 JSON 结构。

## 交互

- 折叠入口始终显示在编辑器行号左侧。
- 点击对象或数组起始行的入口，可折叠其子字段；再次点击恢复展开。
- 初始状态保持全部展开，不新增全局展开/收起按钮或持久化状态。

## 实现

`ConsoleEditor` 是请求编辑器与未截断返回内容查看器共用的 Monaco 封装。为该组件配置 Monaco 原生折叠能力，并确保当前 `es-console` 语言按缩进识别折叠区域。由于两处调用均复用该组件，功能会同时生效。

被截断的返回内容继续使用现有纯文本预览。该内容不完整，无法可靠推断完整 JSON 的字段层级，因此不提供字段折叠。

## 错误处理

折叠功能只影响展示，不改变内容、校验、补全、格式化、快捷键或请求执行流程。格式不完整或不符合 JSON 的输入继续由既有编辑器行为处理；无法形成层级的行不显示折叠入口。

## 测试

为 `ConsoleEditor` 补充组件测试，验证 Monaco 配置启用折叠并将折叠控件设为始终显示；覆盖可编辑和只读两种调用路径，确保请求内容和返回内容共享同一行为。
